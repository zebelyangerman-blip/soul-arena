АРЕНА ДУШ R87.1 — ИСПРАВЛЕНИЕ ПОДКЛЮЧЕНИЯ

Обновление поверх установленной R87.0.
Первоначальный вход, профиль, рейтинг и поиск используют HTTP-запросы без дополнительного браузерного OPTIONS-запроса. Подписанный сеанс проверяется сервером. На медленном соединении первый вход получает до 12 секунд; поиск и восстановление ограничены собственными сроками.

Игровая логика, общий движок решений ботов и анимации входят в базовую R87.0. R87.1 обновляет подключение.

Сначала заменить папку online в прежнем серверном проекте и выполнить npm run preflight, npm run deploy, npm run check:server. Затем загрузить содержимое UPDATE_CLIENT в корень существующего GitHub-репозитория игры и дождаться успешной публикации Pages.

В этом комплекте представлены изменённые клиентские файлы. Основные ресурсы берутся из уже установленной R87.0. Полная инструкция находится в 01_INSTALL_RU.txt в корне архива.
